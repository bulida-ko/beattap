# fingerdance assets

핑거댄스(앱인토스 미니앱)의 음원 저장소입니다.

앱 번들에서 음원을 빼기 위해 존재합니다. 곡을 추가하거나 바꿀 때 **앱을 다시
배포하지 않으려는 것**이 전부입니다.

```
audio/
  manifest.json          곡 id → 실제 파일명
  <songId>-<해시8>.mp3   내용 해시가 박힌 음원
```

파일명에 내용 해시를 박는 이유: 깃헙 raw 는 5분 캐시가 걸려서 같은 이름으로
덮으면 한동안 옛 파일이 내려옵니다. 내용이 바뀌면 이름도 바뀌므로 캐시를 비울
일이 없습니다.

갱신은 앱 저장소에서 합니다.

```bash
node tools/push-assets.mjs --push
```
